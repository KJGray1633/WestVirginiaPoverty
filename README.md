# West Virginia Poverty Data Analysis

## Project Overview
This project explores poverty trends in West Virginia through data analysis and visualization. The goal is to uncover insights into socioeconomic conditions across the state, identify patterns in poverty distribution, and support data-driven decision-making for policy and community development.

## Data Sources
- U.S. Census Bureau datasets
- West Virginia state and county-level poverty statistics
- Publicly available socioeconomic indicators

## Features
- Data cleaning and preprocessing of poverty-related datasets
- Exploratory data analysis (EDA) to identify trends and correlations
- Visualizations including bar charts, heatmaps, and geographic plots
- Insights into regional disparities and demographic factors influencing poverty

## Technologies Used
- Python: `pandas`, `matplotlib`, `seaborn`, `geopandas`
- Jupyter Notebook
- Git and GitHub for version control
